# StudyBuddy
StudyBuddy or Companion App To help students organize their academic tasks and build productive study habits.


# Notifications
- Welcome Notification: A notification is scheduled to appear when the user opens the app.
- Assignment Reminders: A notification is scheduled to appear one day before an assignment's due date.
- Study Motivation Reminders: These are scheduled to appear once every 24 hours to provide encouragement based on your study streak.
- Study Timer Countdown: A persistent notification will appear in the status bar as soon as a study session begins, showing the remaining time.
